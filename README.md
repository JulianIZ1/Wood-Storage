# Wood Storage
Wood storage allows you to use the pile of logs in the farmhouse sprite stacked by the front door.

Storage gets larger as you upgrade the house:
Base Level - 1 storage slot
Level 1 Upgrade - 3 storage slots
Level 2 Upgrade - 9 storage slots

## Requirements
- [SMAPI](https://smapi.io/) 4.0.0 or later

## Installation
1. Install [SMAPI](https://smapi.io/) if you haven't already.
2. Download the latest release of Wood Storage.
3. Extract the `WoodStorage` folder into your `Stardew Valley/Mods` folder.
4. Launch the game through SMAPI.

## Compatibility
Because the mod hooks into the existing wood pile object next to the farmhouse, it should work alongside most other mods. As always, back up your save before installing new mods for the first time.
